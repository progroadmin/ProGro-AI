# ProGro.ai Website

Public marketing, information, demonstration-request, contact, and account-access website for ProGro.ai.

## Local development

```bash
npm install
npm run dev
```

The site uses Next.js, TypeScript, Tailwind CSS, and Supabase authentication. Store private environment values in `.env.local`; never commit or distribute that file.

## Production

The production domain is `https://progro.ai`.
